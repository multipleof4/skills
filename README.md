# skills

Personal [Claude Code skills](https://code.claude.com/docs/en/skills).

| Skill | What it does |
|---|---|
| [direct-img](direct-img/SKILL.md) | Find, preview and embed images with [direct-img.link](https://direct-img.link), picking the best candidate for the request, with free (public domain / CC0) images for publishing |

## Install

This repo is laid out as a personal skills folder. If you don't have `~/.claude/skills` yet, clone it there:

```bash
git clone https://github.com/multipleof4/skills ~/.claude/skills
```

Otherwise copy (or symlink) the skill folders you want into `~/.claude/skills/`. Update with `git pull`.
